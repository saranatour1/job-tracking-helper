# Code of conduct

Treat people here with respect. Plenty of people looking at this project are job hunting, and some are having a hard time of it.

## Not okay

- harassment, threats or personal attacks
- insults or slurs about someone's identity, background or employment status
- sexual comments or images
- posting someone's private details without their permission, which includes resumes, emails and job applications
- continuing after someone has asked you to stop

Disagreeing about code is fine. Be direct about the code and leave the person out of it.

## Where this applies

Issues, pull requests, reviews and anywhere else you're speaking for the project.

## Reporting a problem

Use [GitHub's report form](https://github.com/contact/report-abuse), or the **Report content** option on the comment.

The maintainer can edit or delete comments, close threads, and block people from the project. Tell us if you need to be left out of any public follow-up.
